# Dice Lab — Dice Roll Website

A beginner-friendly dice roller built with HTML, CSS and vanilla JavaScript for **Problem Statement 1: Dice Roll Website**.

## Features

- Roll one to six standard six-sided dice.
- More dynamic tumbling animation with a little landing bounce.
- Generated dice-rattle sounds during the roll and a soft landing sound.
- Sound on/off toggle.
- Dice faces drawn with CSS pips (not just numbers).
- Displays the total of the dice.
- Keeps the last eight rolls in a history list.
- Responsive layout for phones and desktops.
- Clear-history button.

## Tech stack

- HTML for the page structure
- CSS for the layout, colours, dice faces and animation
- JavaScript for random numbers, rolling logic, history and browser-generated sound using the Web Audio API

## Run locally

1. Download or clone this repository.
2. Open `index.html` in your browser.

No packages or build tools are required.

## How randomness works

The function `randomDie()` uses:

```js
Math.floor(Math.random() * 6) + 1
```

`Math.random()` returns a decimal from 0 (inclusive) to 1 (exclusive). Multiplying by 6 and using `Math.floor()` creates a number from 0 to 5. Adding 1 gives a whole number from 1 to 6.

This is suitable for a simple game demo, but `Math.random()` is not intended for security-sensitive randomness.

## Sound note

The rolling sound is generated by JavaScript with the browser's Web Audio API, so the project does not need a separate audio file. Most browsers only play audio after a user interaction, so click the sound toggle or roll button to enable it. Use the SOUND ON/OFF button to mute it.

## 🎮 How to Play


-Select the number of dice you want to roll (1–6).

-Click Roll Dice to roll and watch the animations.

-Check your total score after each roll.

-View your recent rolls in the history section.

-Use the sound toggle to turn sound effects on or off.

-Clear the roll history whenever you want.
